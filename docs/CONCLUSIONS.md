# 结论层：从证据反推“怎么拍、怎么剪”

这一层交给 LLM（目前是 Claude）。输入是 `runs/<名字>/` 文件夹：
- `evidence.json`：测量层的全部数字
- `sheets/*.jpg`：每个镜头的关键帧（编号、开始时间、时长）
- `rhythm.png`：节奏曲线
- 对比模式时，还有 `gap.json`

## 铁律
1. **每条结论都要带证据**：附上镜头编号、时间戳，或者 evidence.json 里的数字，让人能回原片核对。
2. **分清来源**：每条结论标 `[测量]`（数字直接来自脚本）或 `[推断]`（看图判断、推测意图）。推断的内容再标可信度：高 / 中 / 低。
3. **看图归类**：镜头类型（俯拍、微距、屏幕录制、口播、手部操作、空镜……）靠看联系表判断，不要只凭运镜数据猜。
4. **写成能照做的**：不写“节奏很好”这种空话，要写“开头 30 秒每 1.1 秒切一刀，讲完结论留 0.6 秒再切”。

## 输出结构

### 1. 一句话风格总结

### 2. 分镜配方（3 到 6 类）
每类镜头写一张卡片：
```
【配方 X：名称】占比 __%（按时长），单个 __–__ 秒
机位：
运动：
光线：
景别 / 镜头：
用在什么时候：
示例：#12 0:42、#30 1:15 ...
```

### 3. 剪辑规则
- 基础节奏：平均、中位镜头时长，开头、中段、结尾各怎么变。
- 切点放在哪：句末、节拍、动作，还是停顿里？引用 `cut_alignment` 的数字。
- 镜头类型怎么轮换：会不会连用同一类？屏幕录制和实拍怎么穿插？
- 停顿和留白：讲到关键点之后怎么处理。

### 4. 布光推断 `[推断]`
主光方向和大小（看阴影的方向和软硬），有没有轮廓光，背景和主体的明暗关系（参考 `center_vs_edge`），色温倾向。每条标可信度。

### 5. 拍摄清单
下次开拍前用的 checklist：每类镜头要拍几条、要什么器材、灯怎么摆。

### 6. 对比模式：改进清单
按差距大小排序，取前 5 条。每条写清楚：问题，参考视频的数字和你的数字，下次具体怎么改。

### 7. `style_profile.json`
最后输出一份机器可读的配置，给自动剪辑用：
```json
{
  "shot_len": {"first_30s": 0, "middle": 0, "last_30s": 0},
  "cut_on": {"sentence_end": 0, "beat": 0, "onset": 0},
  "avoid_cut_mid_word": true,
  "pause_after_key_point_s": 0,
  "shot_mix": {"<类型>": 0},
  "max_same_type_in_row": 0,
  "look": {"contrast": "", "warmth": "", "background": ""}
}
```
